Plugin para Claude Code

Do banco legado ao painel executivo, com cada número conferido.

O Archeo conecta bancos de dados legados a assistentes de IA. Este plugin dá ao Claude as skills para criar ferramentas no Archeo MCP Creator, montar painéis de varejo e gerar relatórios de ERP, sempre validando o SQL no banco real antes de entregar.

O problema

Cadastrar uma boa ferramenta não é só escrever um SELECT.

Em um schema que ninguém documentou, cada etapa tem uma armadilha.

O risco

Um detalhe errado não dá erro.

A ferramenta devolve zero linhas, ou um número inflado, e ninguém percebe.

  1. 1Achar a tabela ou view certa num schema sem documentação.
  2. 2Descobrir quais registros excluir: cancelados, estornados, marcados para expurgo.
  3. 3Transformar filtros em parâmetros $1, $2, ... com o tipo certo.
  4. 4Escrever uma descrição que outro modelo de IA entenda sem ambiguidade.
  5. 5Testar tudo antes de publicar.
Skills

Dez skills para o trabalho que ninguém quer fazer.

Você pede em português, com os nomes que já usa no ERP. A skill certa entra em ação.

Pergunta de negócio vira ferramenta pronta.

O Claude explora o banco conectado ao Archeo, escreve o SQL, roda no banco real e devolve a ficha pronta para copiar e colar na tela Nova ferramenta do MCP Creator.

  • Datas com fim exclusivo (>= início AND < fim), sem perder o último dia nem matar o índice.
  • "Todos" sem armadilha: filtro opcional com sentinela (0 = todas as lojas).
  • Somas à prova de nulo com COALESCE dentro de expressões compostas.
  • Tipos como contrato: o tipo do parâmetro valida a entrada antes do banco.
  • Validação obrigatória em pelo menos dois cenários. Sem validação, a ficha avisa com destaque.

O relatório que você vai pedir de novo vira ferramenta: cada skill indica os parâmetros e passa para add-mcp-tool o SQL já validado.

Como funciona

Nada sai sem ter rodado no seu banco.

Toda skill segue o mesmo método. Se o teste falha, o Claude diagnostica e ajusta antes de entregar.

01

Identifica o banco.

Qual banco está conectado ao Archeo, a engine e a versão.

02

Explora o schema.

Tabelas, colunas e amostras que respondem à pergunta.

03

Mede os dados.

Volume, período coberto, nulos e flags de cancelamento ou expurgo.

04

Escreve e valida.

SQL com parâmetros, rodado com valores de teste em mais de um cenário.

Falhou? Diagnostica, ajusta e roda de novo até o resultado conferir.

Segurança

Só leitura, sempre.

A skill só lê.

Toda exploração e validação usa as ferramentas somente leitura do conector (db_*).

Um único SELECT.

Sem escrita e sem identificador vindo de parâmetro, o mesmo que o validador do Archeo exige.

Você decide.

Nada é cadastrado automaticamente: você revisa a ficha e decide o que publicar.

Bancos suportados

Funciona no dialeto do seu ERP.

Em qualquer engine, a palavra final é do teste no banco conectado.

SQL ServerValidado
PostgreSQLSuportado
OracleSuportado
MySQL / MariaDBSuportado

Validado: testado contra banco real. Suportado: sintaxe padrão a confirmar no primeiro uso. Se algo não roda, a skill diagnostica e ajusta antes de entregar.

Instalação

Dois comandos no Claude Code.

/plugin marketplace add cd2tec/archeo-claude-plugins
/plugin install archeo@archeo-plugins

Requisito: um conector do Archeo ativo na sessão, com as ferramentas de consulta somente leitura (db_*). Sem ele, a skill avisa e só monta a ficha se você fornecer a estrutura das tabelas, marcada como não validada.
