Plugin para Claude e ChatGPT

Do banco legado ao dashboard e ao relatório que fecha: um agente de IA, assistente do seu ERP, com cada número conferido.

O Archeo conecta bancos de dados legados a assistentes de IA. Com o Archeo MCP Creator, cada consulta vira uma ferramenta que o modelo pode chamar: um SELECT fixo, com parâmetros, que o servidor valida antes de aceitar.

Este plugin tira o trabalho braçal desse processo. As mesmas skills, no Claude Code, no Claude Cowork, no Codex e no ChatGPT Work, geram os relatórios de oito módulos do ERP com prova de reconciliação, montam painéis de varejo e especificam ferramentas para o MCP Creator, sempre validando o SQL no seu banco antes de entregar.

O problema

Tirar um número confiável de um ERP legado não é só escrever um SELECT.

Em um schema que ninguém documentou, cada etapa tem uma armadilha.

O risco

Um detalhe errado não dá erro.

O relatório sai com zero linhas, ou com um número inflado, e ninguém percebe.

  1. 1Achar a tabela ou view certa num schema sem documentação.
  2. 2Descobrir quais registros excluir: cancelados, estornados, marcados para expurgo.
  3. 3Juntar tabelas sem multiplicar linhas: um cadastro com uma linha por loja infla qualquer soma.
  4. 4Saber se o dado merece confiança: custo estimado, campo nunca preenchido, módulo que ninguém usa.
  5. 5Provar o resultado antes de entregar.

Painel e ferramentas

Para acompanhar a operação e automatizar o que se repete.

O painel mostra a operação em 30 segundos. A ficha transforma a consulta que você vai pedir de novo em ferramenta do Archeo MCP Creator.

Painel executivo de varejo, direto do ERP.

Peça um painel e receba uma página pronta para abrir, com os números do ERP ou PDV conectado ao Archeo. O painel não esconde dado ruim: seção sem dado confiável sai do painel e aparece no rodapé com o motivo.

  • Reconcilia cada ranking com a venda total.
  • Detecta custo estimado (margem idêntica em todos os departamentos).
  • Aponta campo nunca preenchido e período anterior sem base de comparação.

Pergunta de negócio vira ferramenta pronta.

Você descreve o que quer em português. O agente explora o banco conectado ao Archeo, escreve o SQL, roda no banco real e devolve a ficha pronta para copiar e colar na tela Nova ferramenta do MCP Creator. Veja uma ficha completa.

  • Datas com fim exclusivo (>= início AND < fim), sem perder o último dia nem matar o índice.
  • "Todos" sem armadilha: o filtro opcional usa um valor sentinela (0 = todas as lojas) e não devolve zero linhas quando o parâmetro chega vazio.
  • Somas à prova de nulo: COALESCE dentro de expressões compostas, para um campo vazio não zerar o total.
  • Tipos como contrato: o tipo do parâmetro na tela valida a entrada antes de chegar no banco.
  • Validação obrigatória no banco conectado, em pelo menos dois cenários. Quando não dá para validar, a ficha avisa com destaque.

Como funciona

Nada sai sem ter rodado no seu banco.

Toda skill segue o mesmo método. Se o teste falha, o agente diagnostica e ajusta antes de entregar.

01

Identifica o banco.

Qual banco está conectado ao Archeo, a engine e a versão.

02

Explora o schema.

Tabelas, colunas e amostras que respondem à pergunta.

03

Mede os dados.

Volume, período coberto, nulos e flags de cancelamento ou expurgo.

04

Escreve e valida.

SQL com $1..$n, rodado no banco com valores de teste em mais de um cenário.

Falhou? Diagnostica, ajusta e roda de novo até o resultado conferir. Só então a ficha sai pronta para copiar e colar.

Segurança

Só leitura, sempre.

A skill só lê.

Toda exploração e validação usa as ferramentas somente leitura do conector (db_*).

Um único SELECT.

Sem escrita e sem identificador vindo de parâmetro, o mesmo que o validador do Archeo exige.

Você decide.

Nada é cadastrado automaticamente: você revisa a ficha e decide o que publicar.

Bancos suportados

Funciona no dialeto do seu ERP.

Em qualquer engine, a palavra final é do teste no banco conectado.

SQL ServerValidado
PostgreSQLValidado
OracleSuportado
MySQL / MariaDBValidado

Validado: testado contra banco real. Suportado: sintaxe padrão a confirmar no primeiro uso. SQL Server, PostgreSQL e MySQL / MariaDB estão validados; o Oracle é suportado e ainda não foi validado. Se algo não roda, a skill diagnostica e ajusta antes de entregar.

Instalação

No Claude ou no ChatGPT.

O plugin é o mesmo em todos os ambientes. Muda só a forma de instalar e de atualizar.

Requisito, em qualquer ambiente: um conector do Archeo ativo na sessão, com as ferramentas de consulta somente leitura (db_*). Sem ele, a skill avisa e só monta a ficha se você fornecer a estrutura das tabelas, marcada como não validada.

Claude · Terminal

Claude Code

Adicione o marketplace e instale o plugin, dentro de uma sessão.

/plugin marketplace add cd2tec/archeo-harness-plugins
/plugin install archeo@archeo-harness
Claude · App

Claude Cowork

No app do Claude, a instalação é pelo ZIP da última release.

Baixar archeo-claude.zip ↓
  1. Só para você: em Customize > Plugins, faça o upload do ZIP.
  2. Para a organização (Owner, planos Team e Enterprise): em Organization settings > Plugins & skills, use Add > Upload a plugin.
  3. Na aba Inventory, em Default access, escolha se o plugin fica disponível, instalado por padrão ou obrigatório. Os membros o encontram em Customize > Plugins > Discover.

codex plugin marketplace add cd2tec/archeo-harness-plugins

OpenAI · Workspace

ChatGPT Work

O admin do workspace importa o repositório, sem baixar nada.

  1. Em Workspace settings > Plugins, use Add > Import marketplace.
  2. Em Source, informe o endereço abaixo. Deixe Path e Branch vazios.
  3. Autorize o GitHub, confira em Import results se o archeo veio de plugins/codex/archeo e defina a Installation policy.
  4. Os membros instalam em Plugins, na barra lateral.
https://github.com/cd2tec/archeo-harness-plugins

O conector do Archeo precisa estar no workspace como app MCP. No Enterprise, a permissão Create plugins with MCPs vem desligada por padrão.
